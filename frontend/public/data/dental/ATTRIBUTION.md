# Dental research references

Two unchanged STL casts: Abdi, Amir; Nouri, Mahtab (2020), Serial 3D Dental Models, Mendeley Data V1, https://doi.org/10.17632/bpnmf2vhsk.1. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

One unchanged JPEG and senior annotation JSON from Aariz Cephalometric Dataset V1, Khalid et al. (2025), https://doi.org/10.6084/m9.figshare.27986417.v1. CC BY 4.0. Dataset license is distinct from the journal article license.

Orthodont CSV: R nlme package 3.1-172, package license GPL >= 2; GPL-2 text is included. Original source: Potthoff and Roy (1964), Biometrika 51, 313–326. Accessed via the CRAN R-universe mirror. Export format is the mirror’s CSV, values unchanged.

The tooth atlas and hardware geometry in src/dental/anatomy.ts are original educational artwork. Public scans, X-rays, statistical measurements and the atlas are independent references; they do not describe the same participant. See manifest.json for original filenames, sizes and SHA-256 fingerprints.
